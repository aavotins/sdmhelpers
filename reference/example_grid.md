# Example raster-grid geometry

A raster-grid object defining the spatial geometry, pixel alignment and
CRS used by the package's raster examples.

## Usage

``` r
example_grid
```

## Format

A `SpatRaster` object created with
[`terra::rast()`](https://rspatial.github.io/terra/reference/rast.html).

## Source

Derived from a reduced section of the Latvian 100-m raster grid.

## Details

File contains only presence cells coded with value `1`.
