# sdmhelpers: Helper Functions for Species Distribution Modelling

The `sdmhelpers` package provides utility functions for species
distribution modelling workflows, including:

## Details

- phenological weighting from circular day-of-year kernel densities;

- temporal overlap estimation on seasonal and daily cycles;

- spatial-fold selection for independent testing;

- threshold-based model evaluation using the true skill statistic;

- fast raster-based spatial kernel density estimation.
