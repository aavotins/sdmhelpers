# Example background locations

Spatial background locations used in fold-selection and model-evaluation
examples.

## Usage

``` r
example_background
```

## Format

A `data.frame` containing 40000 background location coordinates with 2
fields:

- `x`: approximate X-coordinate (EPSG: 3059).

- `y`: approximate Y-coordinate (EPSG: 3059).

## Source

Prepared for package examples and practically used in species
distribution modelling.
