# Example species-presence locations

Spatial presence records used in spatial KDE, fold-selection, and model
evaluation examples.

## Usage

``` r
example_presences
```

## Format

A `data.frame` containing 2778 species presence location coordinates
with 2 fields:

- `x`: approximate X-coordinate (EPSG: 3059).

- `y`: approximate Y-coordinate (EPSG: 3059).

## Source

Prepared for package examples and practically used in species
distribution modelling.
